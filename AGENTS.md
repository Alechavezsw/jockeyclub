# Jockey Connect

Antes de modificar cuotas, cobranzas, imputaciones, Mercado Pago de cuota, débitos o el modal Cobrar cuota, leé `docs/REGLA_MAESTRA_CUOTAS_Y_COBRANZAS.md`.

Cada mes impago se cobra solo, a la tarifa vigente del catálogo, con el recargo de ese mes. Una diferencia entre ese cálculo y el saldo de la ficha no se acredita sin autorización. El navegador no valida solo el importe: el dominio y la base vuelven a controlarlo. Un ajuste sin período no es una cuota. El saldo de la ficha no se reescribe para forzar el cierre.
